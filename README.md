\# Spear Backport Addon



为 \[Backported Spears](https://github.com/Unknowneth/Backported-Spears) 补充多个模组材质的长矛。



\## 内容

\- \*\*Oreganized\*\*：银矛

\- \*\*BetterEnd (New Dawn)\*\*：塔拉斯金矛 / 终末合金矛 / 太古合金矛（含对应矛头）

\- \*\*Caverns \& Chasms\*\*：银矛（魔法伤害）、死灵合金矛（缓慢）、铜矛（氧化/涂蜡）



\## 依赖

\- 必装：Backported Spears

\- 可选：Oreganized、BetterEnd (New Dawn)、Caverns \& Chasms



\## 构建

1\. 下载 Backported Spears 的 jar，放到 `libs/` 目录

2\. `.\\gradlew.bat build`

3\. 产物在 `build/libs/`
